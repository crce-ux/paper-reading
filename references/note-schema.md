# 精读笔记 · 模板与细则

> **管什么**：一篇文献读完之后，笔记长什么样、每条断言怎么标。
> **不管什么**：这篇值不值得读（见 SKILL.md §一）、怎么回填文献表（见 `table-schema.md`）。

## 二、证据标签五态 · 细则

| 标签 | 什么时候用 | 必须带 |
|---|---|---|
| `[Paper]` | 论文**明确写出来**的——结果、方法、作者自陈的局限 | 定位 |
| `[External]` | 论文**以外**的来源——别的研究、指南、数据库 | 引用或链接 |
| `[Analysis]` | **你**从证据推出来的——评析、关联、差异判断 | 推理 + 相关出处 |
| `[Hypothesis]` | **还没验**的解释或想法 | 提议的检验 + 可能证伪条件 |
| `[User]` | 用户 / 他人提供的判断 | 原话或链到的知识 |

### 三条判定纪律

**1. 不标 = 默认 `[Paper]`——而这是最危险的默认。**
一句你推断的话混在论文原话里，三个月后你自己分不出来，最后它会以「文献支持」的名义进综述。

**2. `[Analysis]` 与 `[Hypothesis]` 的界**：
`[Analysis]` 是**你现在就能论证**的（有推理链）；
`[Hypothesis]` 是**要做实验 / 查证才知道**的。
分不清就写 `[Hypothesis]`——**宁可保守**。

**3. `[Paper]` 只保证「论文这么说了」，不保证「这话是对的」。**
标 `[Paper]` 不等于这条证据成立——**语境判定是另一回事**
（原文说「相关」，你写成「证明」，标签还是 `[Paper]` 但已经越界了）。

> 🔴 **标签管「谁说的」，语境判定管「说得对不对」。两件事，别混。**

## 三、定位方式三态

| 态 | 条件 | 引用写成 | 禁止 |
|---|---|---|---|
| **page-grounded** | PDF 页码可靠 | `[Paper: PDF p.3, Fig.2]` | — |
| **structure-grounded** | 页码不可靠，章节 / 图表 / 公式可靠 | `[Paper: 方法·符号解析]` `[Paper: Fig.2]` | **不写页码** |
| **source-limited** | 只有摘要 / 元数据 | `[Paper: Abstract]` | **不写页码，不推断未见的方法与结果** |

> **为什么把引用形式和源可靠性绑在一起**：
> 页码引用看起来最「精确」，所以在页码不可靠时写它，**伤害最大**——
> 它让读者以为你核过那一页。**宁可用粗一点的定位，不要用假精确的。**

### source-limited 下的写法

只能写**作者在摘要里明说的结论**：

```
✅ 作者报告 A 组优于 B 组 `[Paper: Abstract]`
❌ A 组优于 B 组（p=0.02，调整了年龄与病程） `[Paper: Abstract]`
   —— p 值和协变量不在摘要里，你是在编
```

**部分可得时显式标记**：不能评的节写 `本材料无法评估`，不要留空、也不要填。

## 四、深度 → 能支撑什么

| 读到 | 能支撑 | **不能**支撑 |
|---|---|---|
| 仅标题 | ❌ 几乎不能 | 任何实质断言 |
| 仅摘要 | **作者自述的结论** | 方法细节、局限、亚组 |
| 全文 | 精确范围与条件 | （仍须判语境） |

> ⚠️ **越界最常发生在「摘要 + 想象力」**——读得少，写得却像读全了。

## 五、多源交叉（全文拿不到时的做法）

**全文获取失败不是放弃的理由，但必须把「用了哪几个源」摆在明面上。**

一条实测做法（SMART-CAT 研究）：

```
🟢 摘要        ← 一手，但只到作者自述
🟡 注册库      ← 可查终点定义与样本量
🟡 方案论文    ← 可查设计细节
🟡 院方通稿    ← 只能当背景
```

**每条信息标出它来自哪一级**，并写明 **全文未获取**。
**四源交叉不等于全文**——它只是把「不知道」缩到更小的一块。
