# 正反样例

同一篇文献（只用摘要 + 部分全文），两份笔记。**左边过不了 `check_note.py`，右边能过。**

---

## 一、整份笔记

### ❌ 不好

```markdown
## Clozapine response and claustrum connectivity

**PMID**：41234567 ｜ **年份**：2026
**阅读深度**：摘要

### 一句话结论

屏状核功能连接下降预示氯氮平反应差。

### 研究设计

42 例 TRS 患者，静息态 fMRI，随访 12 周。

### 关键结果

| 指标 | 效应量 | 95%CI / P | 定位 |
|---|---|---|---|
| 连接—ΔPANSS | r=−0.41 | p=0.008 | |
| AUC | 0.78 | | |

### 方法亮点与局限

- 样本量在该病种里属少见。
- 局限性：单中心、样本量小。

### 与本项目的关联

- 可以做 TRS 的影像标志物。
```

**七处越界**：
① 无 `定位方式` 行——9/9 笔记缺的就是这一条；
② 阅读深度写「摘要」，却给出了 r、p、AUC——**摘要里不会有这些**；
③ 三处断言**全不标标签**——默认按 `[Paper]` 读，`[Analysis]` 的话混进了论文原话；
④ 「局限性」一句没标定位，且单中心是不是作者说的，无从判断；
⑤ 「可以做 TRS 的影像标志物」是 `[Analysis]`，却与论文结论混排；
⑥ 没有「可引用的关键句」——日后写作时又要回去翻；
⑦ 没有「待验证 / 证伪条件」。

## 二、标签误用五组

| ❌ | ✅ |
|---|---|
| 屏状核连接下降预示疗效差。（无标签） | 作者报告屏状核连接与疗效相关 `[Paper: Abstract]`；我判断横断面不足以称「预示」`[Analysis]` |
| 该研究证明了 X。`[Paper: Abstract]` | 摘要说 X 与 Y 相关 `[Paper: Abstract]`。（**原文说「相关」，写成「证明」是越界**） |
| 可能 ALFF 才是关键指标 `[Analysis]` | 可能 ALFF 才是关键指标 `[Hypothesis]`（检验方式：…；证伪条件：…）<br>——**要做实验才知道的，是 Hypothesis，不是 Analysis** |
| 局限：单中心、样本小 `[Paper: Abstract]` | 局限：单中心、样本小 `[Analysis]`（作者没写，是我说的） |
| （读摘要，写出 r 与 p） | 读摘要就只写摘要载明的——**效应量不在摘要里就不写** |

## 三、定位方式 × 阅读深度：三种越界

| 读到 | ❌ | ✅ |
|---|---|---|
| 仅摘要 | `[Paper: PDF p.4, Table 2]` | `[Paper: Abstract]` |
| 页码不可靠的全文 | `[Paper: p.7]` | `[Paper: 方法·符号解析]` |
| 只拿到片段 | 推断未见的入排标准 | 写 `本材料无法评估` |

> ⚠️ **页码引用看起来最精确，所以在页码不可靠时写它，伤害最大**——
> 它让读者以为你核对过对应页。宁可用粗一点的定位。
